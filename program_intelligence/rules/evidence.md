# Evidence rules

Anchor on identifiers; record source URI/type/author/event time/retrieval time/excerpt; label confidence per `definitions/confidence-rubric.yaml`; never invent values; absence of retrieval is not absence of fact; no causality from correlation; show both sides of conflicts with timestamps; dedupe by content hash plus source relationship; event time for reasoning, retrieval time for freshness; always state queried range and coverage; if definitions differ, ask or report both.
